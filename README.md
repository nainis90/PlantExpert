# PlantExpert 🌱

## Descripción

PlantExpert es un sistema experto que ayudará a identificar posibles enfermedades y problemas de las tomateras mediante preguntas sobre sus síntomas.

Está dirigido a aficionados a la jardinería con tomateras en huertos domésticos al aire libre del País Vasco.

## Objetivo

Desarrollar una aplicación que analice los síntomas indicados por el usuario y muestre posibles causas, explicaciones y recomendaciones generales.

## Problemas estudiados

El proyecto contempla seis problemas:

- Alternariosis o tizón temprano.
- Oídio.
- Mildiu tardío.
- Mancha bacteriana.
- Problemas de riego.
- Posibles carencias nutricionales.

## Funcionamiento previsto

El usuario responderá preguntas sobre los síntomas de su tomatera. El sistema utilizará una base de conocimiento y reglas para relacionar las respuestas con posibles problemas y explicar sus conclusiones.

Si la información es insuficiente o existen varias causas posibles, lo indicará.
